# chartframe v0.1 design

Go plotting for exploratory data analysis, reports, and web pages. Author: alifarid.
This is an initial, deliberately bounded release rather than Matplotlib compatibility.

Use Gonum Plot v0.17.0 for PNG, SVG, and PDF typography and rendering. A small Go API
owns validated data, analysis helpers, themes, export, and dashboard composition.
HTML embeds generated SVG with local pan/zoom and SVG download controls: no CDN,
JavaScript framework, Python process, browser service, or network call at render time.
Viewport zoom is geometric; it does not recalculate axes or aggregate observations.

Alternatives considered: a custom renderer would duplicate fonts/layout/export code;
a browser-only backend would complicate static reports. The selected implementation
uses an established renderer and keeps the scientific data model in Go.

## Contract

The root package is `chartframe`. `New(title string) *Chart` returns a mutable builder.
Builders retain their first validation error; `Err`, `SVG`, `HTML`, `Write`, and `Save`
expose it. Every input slice is copied, including matrix rows. Concurrent reads/renders
are supported after construction; concurrent mutation requires external synchronization.

Chart methods return `*Chart`: `Line(name string, x, y []float64)`, `Scatter` with the
same signature, `Bar(name string, labels []string, values []float64)`,
`Histogram(name string, values []float64, bins int)`, `Box(name string, values []float64)`,
`Heatmap(name string, xLabels, yLabels []string, z [][]float64)`,
`ECDF(name string, values []float64)`, `LinearFit(name string, x, y []float64)`,
`Labels(x, y string)`, `Size(width, height int)`, `Dark()`, `LogX()`, `LogY()`.
`Err() error` is read-only. Dimensions default to 900x540 logical pixels, at 96 dpi;
allowed dimensions are 240..4096. Reject empty data, unequal lengths, nonfinite numbers,
and nonpositive values on logarithmic axes. Reject invalid UTF-8/XML text.

Internal Chart fields shared by implementation files:
`title, xLabel, yLabel string; width, height int; dark, logX, logY bool;
layers []layer; err error`.
Internal layer fields: `kind string; name string; x, y []float64;
labels, yLabels []string; z [][]float64; bins int`.
Kinds are `line`, `scatter`, `bar`, `histogram`, `box`, `heatmap`, `ecdf`.
Histograms and box layers store samples in y; ECDF stores prepared x/y points.
Heatmap cannot coexist with other layers. Box layers coexist only with box layers.
Bar layers coexist only with bars and must have identical category labels. Numeric
line/scatter/histogram/ECDF layers may overlay. Histogram and bar include zero in
the vertical extent except on log axes; logarithmic bar/histogram plots are rejected
because their zero baseline is undefined. Box plots also reject log axes in v0.1.

Exports: `(*Chart).SVG() ([]byte,error)`, `HTML() ([]byte,error)`,
`Write(w io.Writer, format string) error`, `Save(path string) error`.
Formats: svg/png/pdf/html, explicit unknown-format errors. Save renders before opening
the destination and atomically renames a sibling temporary file after a successful write.
Never open arbitrary paths automatically or start external processes.

`Grid(title string, columns int, charts ...*Chart) *Figure` creates a dashboard,
with `SVG`, `HTML`, `Write`, and `Save` matching Chart. Reject empty, nil, or invalid
charts; columns must be 1..4. Figure size derives from chart cells and stays bounded.

Analysis helpers: `FitLinear(x,y []float64) (Regression,error)` where Regression has
`Slope, Intercept, RSquared float64`; reject constant x and unstable/nonfinite results.
`Describe(values []float64) (Summary,error)` where Summary has `Count int` and
`Min,Q1,Median,Q3,Max,Mean float64`; quartiles use sorted linear interpolation
(R type 7). `Bin(values []float64,bins int) (HistogramData,error)` where HistogramData
has `Edges []float64; Counts []int`; bins 1..10000, left-closed/right-open except
inclusive last edge, exactly bins+1 edges, constant inputs get a finite enclosing range.
Reject ranges not representable as finite, distinct float64 edges.

CSV: `ReadCSV(io.Reader) (*Table,error)`, Table contains private `headers []string;
rows [][]string`, with copied `Headers() []string`, `Column(name string) ([]string,error)`,
`FloatColumn(name string) ([]float64,error)`, and `XY(x,y string) ([]float64,[]float64,error)`.
Reject duplicate/empty headers and malformed rows. Numeric conversion is strict and
reports the row/column; no silent null dropping or inference. UTF-8 must be valid.

## Delivery

Test public behavior and verify histogram counts, quartiles, regression accuracy,
input immutability, error propagation, SVG XML, image decode, PDF signature, CSV quoting,
and exported HTML escaping. Include executable examples, real Go benchmarks with
allocations, English README/API documentation, a gallery generated by this Go package,
MIT license, author attribution, and CI. Do not claim superiority over Matplotlib or
Gonum without comparable measurements. No 3D, animation, GUI event loop, GPU rendering,
LaTeX engine, or full statistical modeling is included in v0.1.
